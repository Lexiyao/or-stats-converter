Confidence intervals use the Wald (log-normal) approximation: symmetric on the log scale, CI = exp(β ± zcrit·SE). These will not exactly match profile-penalised-likelihood or exact intervals (e.g. Firth / logistf), so treat derived SE/CI as approximate reconstructions of those. Normal CDF via Abramowitz–Stegun; inverse via Acklam (accuracy ≈ 1e-7).
